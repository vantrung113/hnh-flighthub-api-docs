Nếu thời gian từ lúc Select đến khi Book vượt quá 15 phút, cần gọi /flight/pricequote để xác minh giá không bị nhảy.
        State Chaining Rule: The flightValues token passed to /flight/book MUST be retrieved directly from the /flight/select response (never use the raw string from Search). If elapsed time exceeds 15 minutes, invoke /flight/pricequote to verify price stability.
        状态链核心规则：调用 /flight/book 时的 flightValues 必须来自 /flight/select 的返回结果，严禁直接使用 /flight/search 的原始串。若从验价到生单间隔超过 15 分钟，建议调用 /flight/pricequote 二次核价以防运价跳变。

Mã Nguồn Tích Hợp Hoàn Chỉnh — Full Python Integration Script

        
Đoạn mã Python tích hợp hoàn chỉnh: Đăng nhập → Tìm vé → Chọn giá → Giữ chỗ → Xuất vé

      

    


    

      
Python 3 (Full SGN-HAN Integration Flow)

      
import requests

BASE_URL = "https://sandbox-apihub.tripota.com.vn"

# 1. Đăng nhập lấy Token
auth_res = requests.post(f"{BASE_URL}/api/v1/sign-in", json={
    "partnerCode": "HNH_AGENCY_VN", "userName": "user_dev", "password": "MatKhau@123"
}).json()
token = auth_res["accessToken"]
headers = {"Authorization": f"Bearer {token}"}

# 2. Tìm chuyến bay SGN - HAN
search_res = requests.post(f"{BASE_URL}/api/v1/flight/search", headers=headers, json={
    "system": "VN", "adt": 1, "chd": 0, "inf": 0,
    "flights": [{"leg": 0, "startPoint": "SGN", "endPoint": "HAN", "departDate": "2026-11-17"}]
}).json()
raw_val = search_res["fareDatas"][0]["options"][0]["flightValues"]

# 3. Khóa giá vé (Select)
select_res = requests.post(f"{BASE_URL}/api/v1/flight/select", headers=headers, json={
    "system": "VN", "flightValues": raw_val
}).json()
selected_val = select_res["flightValues"]

# 4. Giữ chỗ (Book - sinh mã PNR)
book_res = requests.post(f"{BASE_URL}/api/v1/flight/book", headers=headers, json={
    "system": "VN", "flightValues": selected_val, "autoIssue": False,
    "contact": {"name": "DAI LY DU LICH", "phone": "+84901234567", "email": "agent@hnh.com"},
    "passengers": [{"index": 1, "type": "ADT", "title": "MR", "surname": "NGUYEN", "givenName": "VAN AN", "gender": True}]
}).json()
pnr = book_res["bookingCode"]
print(f"Đã tạo mã đặt chỗ PNR: {pnr}")

# 5. Xuất vé chính thức
issue_res = requests.post(f"{BASE_URL}/api/v1/flight/issueticket", headers=headers, json={
    "system": "VN", "bookingCode": pnr
}).json()
print("Xuất vé thành công! Số vé:", issue_res["tickets"])
