Authentication — Cơ Chế Xác Thực

Đăng nhập tài khoản B2B và duy trì JWT Bearer Token
ℹ️
Lưu ý xác thực: Tất cả các API (ngoại trừ /sign-in) bắt buộc truyền header Authorization: Bearer <accessToken>. Token có hiệu lực 24 giờ. Đại lý cần lưu refreshToken để gia hạn tự động trước khi hết hạn. 除登录接口外，所有 API 均需携带 Bearer Token。Token 有效期为 24 小时，可使用 Refresh Token 刷新。 All subsequent requests require a JWT Bearer token in the Authorization header. Access tokens are valid for 24 hours.

Luồng Đặt Vé & Chuỗi Token — Booking Flow & State Chaining

Quy trình bắt buộc: Search → Select → Book → (Add-ons) → Issue Ticket → Retrieve
Bước 1
Search Tìm vé
Sinh flightValue thô
→
Bước 2
Select Chọn giá
Sinh flightValue khóa giá
→
Bước 3
Book Giữ chỗ
Sinh mã PNR (bookingCode)
→
Bước 4 (Tùy chọn)
Add-ons Dịch vụ
Mua Ghế, Hành lý, EMD
→
Bước 5
Issue Xuất vé
Sinh số vé điện tử (e-Ticket)
→
Bước 6
Retrieve Tra cứu
Kiểm tra trạng thái TICKETED
⚠️
Nguyên tắc bất di bất dịch của chuỗi giá vé: Chuỗi flightValues truyền vào API /flight/book BẮT BUỘC phải lấy từ kết quả của API /flight/select (tuyệt đối không lấy trực tiếp từ Search). Nếu thời gian từ lúc Select đến khi Book vượt quá 15 phút, cần gọi /flight/pricequote để xác minh giá không bị nhảy. 状态链核心规则：调用 /flight/book 时的 flightValues 必须来自 /flight/select 的返回结果，严禁直接使用 /flight/search 的原始串。 State Chaining Rule: flightValues passed to /flight/book MUST come directly from /flight/select response.

Issue Ticket — Xuất Vé Máy Bay (Trừ Tiền Ký Quỹ B2B)

Thao tác chính thức và không thể đảo ngược — Sinh số vé điện tử 13 chữ số
🚨
Cảnh báo tài chính & Cơ chế Idempotency: Xuất vé là hành động không thể hoàn tác và sẽ trừ trực tiếp vào hạn mức ký quỹ B2B của đại lý. Bắt buộc truyền header X-Idempotency-Key để chống việc mất kết nối mạng dẫn đến gọi lệnh xuất 2 lần trừ tiền trùng lặp! 资金风险与幂等性：出票为不可逆操作，将直接扣减代理商授信额度。请在 Header 中携带唯一 X-Idempotency-Key，防止超时重试导致重复出票扣费。

Full Integration Script — Mã Nguồn Tích Hợp Hoàn Chỉnh

Đoạn mã Python tích hợp hoàn chỉnh: Đăng nhập → Tìm vé → Chọn giá → Giữ chỗ → Xuất vé
Python 3 (Full SGN-HAN Integration Flow)
import requests

BASE_URL = "https://sandbox-apihub.tripota.com.vn"

# 1. Đăng nhập lấy Token
auth_res = requests.post(f"{BASE_URL}/api/v1/sign-in", json={
    "partnerCode": "HNH_AGENCY_VN", "userName": "user_dev", "password": "MatKhau@123"
}).json()
token = auth_res["accessToken"]
headers = {"Authorization": f"Bearer {token}"}

# 2. Tìm chuyến bay SGN - HAN
search_res = requests.post(f"{BASE_URL}/api/v1/flight/search", headers=headers, json={
    "system": "VN", "adt": 1, "chd": 0, "inf": 0,
    "flights": [{"leg": 0, "startPoint": "SGN", "endPoint": "HAN", "departDate": "2026-11-17"}]
}).json()
raw_val = search_res["fareDatas"][0]["options"][0]["flightValues"]

# 3. Khóa giá vé (Select)
select_res = requests.post(f"{BASE_URL}/api/v1/flight/select", headers=headers, json={
    "system": "VN", "flightValues": raw_val
}).json()
selected_val = select_res["flightValues"]

# 4. Giữ chỗ (Book - sinh mã PNR)
book_res = requests.post(f"{BASE_URL}/api/v1/flight/book", headers=headers, json={
    "system": "VN", "flightValues": selected_val, "autoIssue": False,
    "contact": {"name": "DAI LY DU LICH", "phone": "+84901234567", "email": "agent@hnh.com"},
    "passengers": [{"index": 1, "type": "ADT", "title": "MR", "surname": "NGUYEN", "givenName": "VAN AN", "gender": True}]
}).json()
pnr = book_res["bookingCode"]
print(f"Đã tạo mã đặt chỗ PNR: {pnr}")

# 5. Xuất vé chính thức
issue_res = requests.post(f"{BASE_URL}/api/v1/flight/issueticket", headers=headers, json={
    "system": "VN", "bookingCode": pnr
}).json()
print("Xuất vé thành công! Số vé:", issue_res["tickets"])
